# DarsanaMart - Project Documentation

## Project Description

DarsanaMart is an online shopping web application developed using Java, Spring Boot, Maven, MySQL, HTML, CSS, and Thymeleaf.

## Buyer Module

The buyer can:

- Register an account
- Login using username or email
- View products
- Add multiple products to cart
- Remove products from cart
- View cart total
- Checkout
- Place orders
- View order success page
- Write product reviews

## Seller/Admin Module

The seller/admin can:

- Login
- View the Admin Dashboard
- Add products
- Manage products
- Delete products
- View customer orders

## Technologies

- Java
- Spring Boot
- Maven
- MySQL
- JPA / Hibernate
- HTML
- CSS
- Thymeleaf

## Main Application Flow

Register → Login → Products → Cart → Checkout → Place Order → Order Success

## Seller/Admin Flow

Seller Login → Admin Dashboard → Add Product / Manage Products / View Orders

## Database

The application uses MySQL database named `darsanamart`.

Main entities:

- User
- Product
- Cart
- Order
- Review

## Project Status

The main buyer shopping flow and seller/admin management features have been implemented and tested.
