# DarsanaMart

DarsanaMart is an online shopping web application built using Spring Boot, Java, MySQL, HTML, CSS, and Thymeleaf.

## Features

- User Registration
- User Login
- Buyer and Seller Roles
- Product Listing
- Add Products to Cart
- Remove Products from Cart
- User-Specific Cart
- Checkout
- Place Order
- Order Success Page
- Seller/Admin Dashboard
- Add Product
- Manage Products
- Delete Product
- View Orders
- Customer Reviews

## Technology Used

- Java
- Spring Boot
- Maven
- MySQL
- HTML
- CSS
- Thymeleaf
- JPA / Hibernate

## Application Flow

Register → Login → Products → Cart → Checkout → Place Order → Order Success

## Admin/Seller Flow

Seller Login → Admin Dashboard → Add Product / Manage Products / View Orders

## Project Structure

- `src/main/java` – Java source code
- `src/main/resources/templates` – HTML/Thymeleaf pages
- `src/main/resources/application.properties` – Application configuration
- `pom.xml` – Maven dependencies
